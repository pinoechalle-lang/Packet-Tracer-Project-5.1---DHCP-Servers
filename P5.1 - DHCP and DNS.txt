=========================================================================================
DHCP Server
=========================================================================================

==========[ Configure DHCP Service ]==========

> (1) Press on Server icon
> (2) Go to "Services" tab
> (3) Select on "DHCP"
> (4) Select on "Service" = "On"


==========[ serverPool (default) ]==========

Start IP Address:          10 - 0 - 2 - 16
Subnet Mask:               255 - 255 - 255- 248
Maximum Number of Users:   <1-7>

// Note: Everything is default here

=========================================================================================
DNS Server
=========================================================================================

==========[ Configure DNS Service ]==========

> (1) Press on Server icon
> (2) Go to "Services" tab
> (3) Select on "DNS"
> (4) Select on "DNS Service" = "On"


==========[ companyrecords (domain) ]==========

Name:      companyrecords.local
Type:      A Record  
Address:   172.19.20.1
